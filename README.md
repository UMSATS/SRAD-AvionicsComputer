# SRAD-AvionicsComputer
This repository contains the KiCad design files for the SRAD Computer

# Project Structure
- `Avionics_SRAD.kicad_sch` # Top-level schematic
-  `Avionics_SRAD.kicad_pcb` # PCB layout
-  Avionics_SRAD-backups/ # auto-generated backups
-  Footprints/ # Custom footprints and symbols

# Sensor Modules
- `gyroscope_sketch` → **ASM330LHHX** – Gyroscope
- `accelerometer_sketch` → **KX134-1211** – Accelerometer
- `magnometer_sketch` → **MMC5983MA** – Magnetometer
- `barometer_skecth` → **MS5607-02BA03** – Barometer
- `temperature_sketch` → **MCP9808** – Temperature Sensor
- `GPS_sketch` → **MAX-M10S** – GPS Module
- `NAND_flash_chip_sketch` → **AS5F31G04SND-08LIN** – Flash Storage
